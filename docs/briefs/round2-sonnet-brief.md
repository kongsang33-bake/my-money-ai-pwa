## ต้นแบบ (ยกมาจาก rental-app)

repo `kongsang33-bake/rental-app` branch `master`:
- `app/hooks/useExitingList.ts`: hook + `collapseOnExit` + `restoreRow`
- `app/lib/exiting-list.ts` + `app/lib/__tests__/exiting-list.test.ts`: ตรรกะล้วน (`nextExitSnap`, `mergeExitRows`, `keySig`) พร้อมเทส

ยกมาไว้ที่ `lib/exiting-list.ts` (ตรรกะ + เทสแบบ `node:test` ตามไฟล์เทสอื่นใน `lib/`) และ `components/exiting-list.tsx` (hook + ref callbacks) แปลคอมเมนต์เป็นภาษาอังกฤษตามสไตล์ repo นี้ และตัดส่วนแถวตาราง `<tr>` (`collapseTableRow`) ออก เพราะแอปนี้ไม่มีตาราง

**ต้องมีการแก้บั๊ก 2 ตัวที่ rental-app เคยเจอ (ในต้นแบบแก้แล้ว ห้ามทำหาย)**:
1. รายการที่สร้างใหม่ทุก render (เช่น `.filter()` ใน render) เคยทำให้ setState วนจน "Too many re-renders" วิธีแก้คือเทียบชุด key (`keySig`) ไม่ใช่เทียบ reference ของ array
2. พิมพ์ค้นหาแล้วล้างเร็วๆ เคยทำให้แถวกลับมาแต่ค้างสูง 0 วิธีแก้คือนับเฉพาะแถวที่หายจากข้อมูลจริง (`source`) ไม่ใช่หายเพราะตัวกรอง และใช้ `restoreRow` เป็น ref ของแถวปกติ

กติกาจากต้นแบบที่ต้องคงไว้: หายพร้อมกันเกิน 3 แถวให้หายทันที (เช่นเปลี่ยนเดือน), เปลี่ยน `scope` แล้วให้ล้างทันทีไม่ยุบ, และคำนวณตอน render ไม่ใช่ใน effect

ค่าเวลาให้ใช้ token: อ่านค่า ms จาก `lib/constants.ts` (เพิ่มค่าใหม่ไว้ที่นั่นถ้ายังไม่มี) ส่วน easing ให้ตรงกับ `--e-out` ใน `globals.css` และใส่คอมเมนต์บอกว่าต้องแก้คู่กัน เพราะ Web Animations อ่าน CSS variable ตรงๆ ไม่ได้

## ใช้ที่ไหน

| หน้า | รายการ | `source` | `scope` |
|---|---|---|---|
| รายการ (`components/history.tsx`) | แถวในแต่ละวัน | รายการทั้งเดือนก่อนกรอง/ค้นหา | เดือนที่เลือก |
| งบ (`BudgetsView`) | แถวงบ | – | – |
| เป้าหมาย | การ์ดเป้าหมาย | – | – |
| ลูกหนี้ (`components/debtors.tsx`) | แถวลูกหนี้ | – | ชนิด (ยืม/ให้ยืม) |
| กระเป๋าบัตร (แผงจัดการ) | แถวการ์ด | – | – |

ข้อควรระวังเฉพาะแอปนี้:
- **`SwipeEntry`**: แถวที่ปัดเปิดปุ่มลบค้างอยู่ ตอนยุบต้องยุบทั้งกล่อง (รวมปุ่มที่โผล่) ไม่ใช่แค่ชั้นที่เลื่อน
- **ย้อนคืน (undo)**: ลบแล้วกด "ย้อนคืน" แถวต้องกลับมาปกติ (key เดิม → `restoreRow`) ให้เขียนลำดับนี้ลงในเทสของ `lib/exiting-list.ts` ด้วย
- **หัววันใน History**: ถ้าลบรายการสุดท้ายของวัน หัววันจะหายทันที ยอมรับได้ ไม่ต้องยุบหัววัน แต่ให้จดไว้ในรายงาน
- `.phone` เป็นตัวเลื่อน ห้ามใช้ `window.scrollY`
