Redesign pitch — merged decision

สว่าง = B, มืด = C

สรุปตามที่เลือก: โหมดสว่างใช้จานสี Color-Blocked Bento (B) ที่สนุกจัดจ้าน และ โหมดมืดใช้ Neon Terminal (C) ที่ดูจริงจังกว่า — สลับปุ่มด้านล่างเพื่อดูจอเดียวกันในสองธีมนี้ (ใช้ HTML/โครงหน้าเดียวกันเป๊ะ ต่างกันแค่ชุด token ที่แม็พเข้าไป เหมือนวิธีที่จะทำจริงใน globals.css)

ข้อควรรู้: B และ C ต่างกันมากกว่าแค่สี — รัศมีขอบ (โค้งมนมาก vs โค้งพอดี), เงา (นุ่มสีสัน vs เรืองแสงเฉพาะจุด), และวิธีเน้นหมวดหมู่ (เติมสีเต็มบล็อก vs เส้นขอบสี) ก็ต่างกันด้วย งั้น token ที่ทำใน Step 1 จะต้องรวมค่าพวกนี้เข้าไปด้วย ไม่ใช่แค่สีอย่างเดียว — ยังอยู่ในกฎเดิมของ CLAUDE.md ที่ว่า «ธีมมืดเกิดจากการชี้ token ใหม่ ไม่ต้องเขียนกฎ dark-mode แยกทีละคอมโพเนนต์» เพราะเราจะยัดค่าที่ไม่ใช่สีเข้าไปเป็น token ด้วยเหมือนกัน

ทางเลือกทั้งหมดที่สำรวจไว้ก่อนสรุป — เผื่ออยากหยิบรายละเอียดจากแบบอื่นเพิ่ม
